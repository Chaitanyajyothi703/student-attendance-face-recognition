# Student Attendance System Using Face Recognition

## Project Description
This project is a Student Attendance System using Face Recognition.
It is developed using Python and OpenCV.

The system captures the student's face, recognizes the face using a trained model, and automatically marks attendance with the student's name, date, and time.

## Technologies Used
- Python
- OpenCV
- Haar Cascade
- Face Recognition
- CSV

## Features
- Capture student face images
- Train the face recognition model
- Detect and recognize faces
- Automatically mark attendance
- Store attendance with date and time

## Project Files
- `main.py` - Main program
- `capture_faces.py` - Captures face images
- `train_model.py` - Trains the face recognition model
- `attendance.py` - Marks attendance
- `attendance.csv` - Stores attendance records
- `trainer.yml` - Trained face recognition model

## How It Works
1. Capture face images of the student.
2. Train the face recognition model.
3. Start the attendance system.
4. The camera detects and recognizes the face.
5. Attendance is automatically recorded with date and time.

## Output
The attendance is stored in a CSV file.
